Implemented a complete Python 3.13 `uv` project with package `joukowskisim`.

- Mathematical formulation: 2D incompressible vorticity–streamfunction Navier–Stokes equations with mapped Jacobian, split viscous integration, pressure post-processing, circulation, lift, drag, wall slip, and energy diagnostics.
- Mapping: chord-normalized offset-circle Joukowski map using logarithmic radius. The airfoil is exactly the `s=0` boundary. A finite `te_gap=0.015` avoids the cusp singularity and keeps the analytic metric positive.
- Numerical method: Fourier spectral derivatives using multithreaded SciPy FFTs, Chebyshev–Gauss–Lobatto radial collocation, cached modal LU Poisson solves applied through four coarse parallel LAPACK batches, Fourier 2/3 dealiasing, a nonlinear-only Chebyshev-tail filter, and LS-IMEX-RK3 with the complete variable-metric radial-plus-azimuthal diffusion operator treated implicitly by matrix-free GCROT.
- Boundaries: constant wall streamfunction, cubic generalized Thom wall-vorticity reconstruction included as an algebraic row in every coupled implicit stage, a cached radial/Schur inverse used as the Krylov preconditioner, zero outer vorticity, mapped free-stream Dirichlet data, and a deterministic compatible no-slip initial layer without a timestep-count ramp.
- Pressure/Cp: pressure-Poisson reconstruction with outer pressure reference, surface Cp, pressure lift and drag, plus a clearly labeled contour-circulation lift estimate distinct from the inviscid Kutta circulation.
- GUI: responsive PySide6 worker thread, dark theme, editable solver/grid controls, cached flat-index/weight physical rasterization, one-step frame cadence, NumPy colormaps, accurate airfoil overlay, current local DateTime and elapsed wall-time displays that continue through pauses, integer cumulative simulation FPS plus simulation-time/wall-time throughput, diagnostics, and a Qt-native Cp chart comparing viscous and analytical Kutta–Joukowski profiles.
- Performance: on the development M1 Max, a 30-frame 160×512 solver/pressure/diagnostic/render reference loop measures 2.40 raw FPS, down from the radial-only solver's roughly 15 FPS, but advances simulation time about 6.6× faster. A stable 100-step headless run reaches `t=0.01491` in 35.88 seconds (2.79 steps/s and `4.16e-4` simulation-time units per wall second). Production defaults are Re=10000 on a 240×768 grid.
- Tests: `49 passed`, including production-default consistency, DateTime/wall-clock formatting, direct dense/full-operator stage agreement, a low-Re automatic-step refinement case, a stiff `k_theta=20` decay case at 100× the former angular limit, singular-map rejection, fast/full Poisson wall-functional agreement, parallel real/complex cached-LU parity and immutability, IMEX wall-coupling/cache checks, measured split-order behavior, small-timestep continuity, radial nonlinear filtering, GUI FPS timing/reset isolation, geometry, pressure, symmetry, wake, and headless validation.
- Timestep probe: at the 160×512, Re=1000 reference initial state, the production timestep is `8.331e-5`; the counterfactual explicit-theta limit is `2.999e-6` and the all-explicit limit is `3.004e-9`. Full implicit diffusion therefore gives a 27.8× increase over the previous radial-only IMEX timestep.
- Limitations: finite trailing-edge regularization, approximate wall-vorticity closure, finite outer boundary, remaining advective limit, first-order pure-implicit accuracy in the supplied LS recurrence, iterative full-stage cost/tolerance, `O(Ntheta*Nr^2)` radial-factor memory, and a conservative fallback for intentionally underresolved Nr<40 smoke-test grids. High-Reynolds-number cases require careful resolution; this remains a 2D laminar/unsteady solver without turbulence modeling. The running backend is the SciPy/NumPy float64 reference; `prompt.txt` defines correctness and end-to-end performance gates for a future persistent MLX backend.

Run:

```bash
uv run simulation
uv run pytest -q
uv run python -m joukowskisim.main --headless --steps 100
```
