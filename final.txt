Implemented a complete Python 3.13 `uv` project with package `joukowskisim`.

- Mathematical formulation: 2D incompressible vorticity–streamfunction Navier–Stokes equations with mapped Jacobian, split viscous integration, pressure post-processing, circulation, lift, drag, wall slip, and energy diagnostics.
- Mapping: chord-normalized offset-circle Joukowski map using logarithmic radius. The airfoil is exactly the `s=0` boundary. A finite `te_gap=0.015` avoids the cusp singularity and keeps the analytic metric positive.
- Numerical method: Fourier spectral derivatives using multithreaded SciPy FFTs, Chebyshev–Gauss–Lobatto radial collocation, cached modal LU Poisson solves, Fourier 2/3 dealiasing, a nonlinear-only Chebyshev-tail filter, and LS-IMEX-RK3 with stiff radial diffusion treated implicitly.
- Boundaries: constant wall streamfunction, cubic generalized Thom wall-vorticity reconstruction coupled through a cached Schur solve, zero outer vorticity, mapped free-stream Dirichlet data, and a deterministic compatible no-slip initial layer without a timestep-count ramp.
- Pressure/Cp: pressure-Poisson reconstruction with outer pressure reference, surface Cp, pressure lift and drag, plus circulation-based lift.
- GUI: responsive PySide6 worker thread, dark theme, editable solver/grid controls, cached physical-space inverse-map rasterization, NumPy colormaps, accurate airfoil overlay, integer cumulative simulation FPS, diagnostics, and a Qt-native Cp chart comparing viscous and analytical Kutta–Joukowski profiles.
- Tests: `33 passed`, including IMEX wall-coupling/cache checks, measured split-order behavior, stiff decay above the explicit limit, small-timestep continuity, radial nonlinear filtering, GUI FPS timing/reset isolation, geometry, operators, pressure, symmetry, wake, and 100-step headless validation.
- Timestep probe: at the default 160×512, Re=1000 case, the IMEX timestep is `2.999e-6` versus the equivalent all-explicit limit `3.004e-9`, approximately a 998× increase.
- Limitations: finite trailing-edge regularization, approximate wall-vorticity closure, finite outer boundary, remaining explicit azimuthal/advection limits, first-order pure-implicit accuracy in the supplied LS recurrence, `O(Ntheta*Nr^2)` factor memory, and a conservative fallback for intentionally underresolved Nr<40 smoke-test grids. High-Reynolds-number cases require careful resolution; this remains a 2D laminar/unsteady solver without turbulence modeling. The running backend is the SciPy/NumPy float64 reference; `prompt.txt` defines correctness and end-to-end performance gates for a future persistent MLX backend.

Run:

```bash
uv run simulation
uv run pytest -q
uv run python -m joukowskisim.main --headless --steps 100
```
